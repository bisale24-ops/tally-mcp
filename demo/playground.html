What is real here

  • Every answer comes from the Tally MCP server over an MCP client session. Nothing is scripted.
  • A language model plays Alexa+'s routing: it sees only the tool list the server publishes and picks a tool. The grey line under each sentence is that call.
  • The spoken reply is the tool's own text, read verbatim, as an Echo does. The screen is the server's MCP Apps resource, fed the same structured result.
  • If the model is unreachable, a small pattern router takes over and the line is marked fallback.
